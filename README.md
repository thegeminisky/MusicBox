# 云乐盒

一个轻量的 Android 音乐播放器。作为第三方客户端，它只做一件事：**让你更快地把想听的歌播起来**——打开就是歌单，点一下就播，搜索、收藏、缓存、导出都在一两下之内完成。

> 使用自己的账号登录后即可读取歌单与歌曲信息。账号凭据只保存在本机，仅用于向音乐服务请求你的数据，不会发送给本项目作者或其他第三方。

## 主要功能

- **快捷播放**：首页直接展示每日推荐、心动模式、我的歌单；进入歌单可自动播放，点击任意歌曲立即切换
- **完整播放控制**：顺序 / 列表循环 / 单曲循环、播放队列、后台播放、通知栏与锁屏控制
- **搜索**：输入歌名或歌手，找到即可直接播放
- **收藏与发现**：每日推荐、红心歌曲、自建歌单、榜单与新歌速递
- **音质选择**：标准、较高、极高、无损等档位，随时在设置里切换
- **离线缓存**：听过的歌曲自动缓存，可自定义空间上限（0.5G–20G）与歌曲数量上限
- **导出音乐**：歌曲右侧「⋯」→「导出音乐」，通过系统文件选择器保存到任意位置
- **回到官方 App**：同一菜单里「复制歌名并打开网易云」，自动复制「歌名 歌手」并跳转官方客户端，方便在官方应用里加入歌单
- **个性化设置**：音质、缓存、自动播放范围、预加载、拔出耳机暂停等

## 开始使用

1. 到本仓库的 **Releases** 页面下载最新版 `musicbox.apk`，安装到 Android 8.0 及以上设备
2. 首次打开进入登录页，用你自己的账号登录
3. 首页点开歌单即可播放，或切到「搜索」直接找歌

### 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 播放整个歌单 | 歌单页顶部「播放全部」 |
| 切歌 / 查看播放列表 | 底部播放条，点右侧队列图标 |
| 换音质、清理缓存 | 「设置」→ 音质 / 缓存管理 |
| 导出单曲 | 歌曲右侧「⋯」→「导出音乐」 |
| 在官方应用里加歌单 | 歌曲右侧「⋯」→「复制歌名并打开网易云」 |

## 获取更新

代码提交后由 GitHub Actions 自动构建，APK 统一发布在 **Releases** 页面，仓库内不包含二进制产物。开发者也可在本地用 `scripts/build.ps1`（Windows）或 `scripts/build.sh`（Linux）自行构建。

## 其他

- 版本号为 `主版本.小版本.提交序号`，例如 `1.2.0`
- 「设置 → 关于」可查看当前版本、构建时间与提交哈希，并跳转到本仓库
